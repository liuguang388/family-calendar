# 🏠 萌家日历 - 家庭共享事件助手

一个专为家庭设计的共享事件日历，可以在微信等群聊中分享使用。支持文字、图片、视频、录音等多种事件类型，帮助家庭成员（特别是孩子）管理每日日程。

## ✨ 功能特色

- 📅 **可爱日历视图** - 月历展示，有事件的日子会有彩色小圆点
- ✅ **事件管理** - 添加、完成、删除事件（过去日期只读）
- 🎙️ **多媒体支持** - 事件可附加文字、图片、视频、录音
- 🏠 **家庭共享** - 一个密码全家通用，无需个人注册
- 🎨 **每日主题** - 每天自动切换不同的可爱配色和动漫风格
- 📱 **手机优先** - 完美适配手机浏览器，微信群内直接打开

## 🚀 快速开始

### 方式一：直接运行（推荐）

```bash
npm install
npm start
```

然后在浏览器打开 `http://localhost:3456`

把链接分享到微信群，家人用相同的家庭名称和密码即可加入。

### 方式二：部署到服务器

```bash
# 使用 pm2 后台运行
npm install -g pm2
pm2 start server.js --name family-calendar
```

## 🔒 权限说明

- **今天和未来**：可以添加、编辑、完成、删除事件
- **过去日期**：只能查看，不能修改内容（可以切换完成状态）
- **家庭共享**：知道家庭名称和密码的任何人都可以查看和编辑

## 🛠 技术栈

- 后端：Node.js + Express + SQLite3
- 前端：原生 HTML/CSS/JS（无框架依赖，超轻量）
- 文件存储：本地磁盘（uploads 目录）

## 📁 目录结构

```
family-calendar/
├── server.js          # 服务端主文件
├── package.json       # 依赖配置
├── database.sqlite    # 数据库文件（自动创建）
├── public/            # 前端文件
│   ├── index.html     # 主页面
│   └── app.js         # 前端逻辑
└── uploads/           # 上传的多媒体文件
```

## 💡 小贴士

1. **微信群使用**：部署后将链接发到群里，家人点击即可使用
2. **家庭密码**：建议设置简单易记的密码，方便老人孩子使用
3. **录音功能**：需要浏览器允许麦克风权限
4. **数据备份**：定期备份 `database.sqlite` 和 `uploads/` 目录
